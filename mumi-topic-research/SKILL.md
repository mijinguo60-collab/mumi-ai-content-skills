# Mumi 选题调研

把选题改成可验证任务：谁，在什么场景，用哪个大陆直连工具，要得到什么结果。选题不是给模型找一个漂亮标题，而是为一次真实工作流测试建立证据。

调研真实用户痛点、近期公开讨论、官方文档和相近内容；区分“有人讨论”和“有人解决”。记录来源、日期和不可访问页面，不把点赞量当成转化证明。必须把账号目标人群（打工人、副业党、自媒体新手）和一个具体任务对上。最终输出 GO / 收窄 / 暂缓，以及最小实测计划：输入材料、操作步骤、成功判据和失败记录；没有完成实测，就不能写“实测有效”。

输出 `选题调研.md`，所有时效性事实紧跟来源和访问日期。没有证据就标记待验证，不猜热度。
