# Mumi聊Ai 内容运营技能包

这是给 Meta Muse 调用的自动化内容生产技能包，服务于账号：**Mumi聊Ai**。

> Mumi｜不讲虚的，只讲能直接抄走的 AI 干货

## 已确认的账号规则

- 目标人群：想用 AI 提效搞钱的普通人，包括打工人、副业党、自媒体新手。
- 内容：工作流式教程，每篇带读者用 AI 完成一件具体的事，附可复制的提示词、模板和检查清单。
- 差异化：每条内容先实测，再发布；只写中国大陆直连工具：豆包、Kimi、DeepSeek、腾讯元宝、文心一言、WorkBuddy。
- 视觉 IP：三只完全同款的黑色手绘企鹅。动作、表情、服装、道具和站位可以变化，角色本体不能漂移。
- 发布平台：小红书、抖音图文共用一套图片内容；微信公众号使用同一选题，但独立写成长文并独立排版。

## 技能目录

- `mumi-content-pipeline`：总编排，负责平台分支、风格锁、自动质检和发布门槛。
- `mumi-topic-research`：选题调研和实测证据。
- `mumi-writer`：小红书/抖音图文文案与公众号独立长文。
- `mumi-copy-review`：去 AI 味、事实、合规和发布前质检。
- `mumi-penguin-visuals`：Punk 风格选择、企鹅参考库调用、图片提示词和视觉一致性。
- `mumi-gzh-design`：按 `gzh-design-skill` 方法生成公众号正文 HTML 和预览文件。
- `mumi-voice-video`：口播视频后续模块，本次图文测试不调用。

## Muse 执行原则

Muse 应该自动完成调研、写作、选风格、选企鹅动作、生成图片、排版和质检。只有通过所有硬门槛才允许发布；图片文字错误、风格不一致、企鹅数量或站位不符合要求时，自动重试，仍失败则停在草稿，不发布。

本仓库不保存任何 API key。外部生图服务只能由 Muse 使用运行时凭据或它可用的图像工具调用。
