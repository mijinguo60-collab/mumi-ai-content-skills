# 公众号主题选择

一篇文章只选择一个主题。没有用户指定时，由 Muse 根据题材自动选择并写入决策记录。

| 主题 | 适用内容 |
| --- | --- |
| 摸鱼绿 | 教程、工具实测、清单、工作流，默认推荐 |
| 红白色系 | 强观点、深度分析、避坑警示 |
| 石墨极简风 | 科技、专业方法、产品分析 |
| 留白禅意风 | 极简、生活化、思考型文章 |
| 摸鱼票据风 | 工具对比、创意测评、步骤复盘 |
| 橄榄手记 | 内部笔记、案例复盘、深度记录 |

主题只决定公众号排版语法；文章中的插图、提示卡和分隔图仍必须继承同一篇内容的 Punk `style_lock`。
